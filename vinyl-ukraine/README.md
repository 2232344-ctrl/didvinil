# VINYL UKRAINE

Каталог українських магазинів вінілу, hi-fi та аудіо — https://vinil.in.ua

- `data.csv` — джерело даних для сайту (колонки A–Y, рядок 1 — заголовок, дані з рядка 3).
- `vendors.json` — повна копія бази (поле `v` = колонки A–W + адреса; `hidden` — приховані картки).
- `data.php` — серверний кеш для сайту: тягне `data.csv` звідси (кеш 10 хв).

Оновлення робить Claude: зміни в базі → коміт сюди.
